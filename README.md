# Saudi Hypermarket Retail Performance & Customer Insights Analytics

📌 Project Overview

This project focuses on analyzing retail store transactions and branch performance metrics to identify meaningful business insights related to sales revenue, regional distribution, product category demand, payment methods, and customer satisfaction.

Python is used for data cleaning, preprocessing, exploratory data analysis (EDA), and trend analysis. Power BI is used to create interactive dashboards and visualize key business insights

📊 Dataset Information

* **Original Source:** [Prime Levels Data Hub](https://prime-levels.com/data-hub/saudi-hypermarket-branch-performance-2024-2026)
* **Raw Data:** https://github.com/roslinmba-dotcom/Saudi_Hypermarket_Branch_Performance_RawData

* 📋 Dataset Summary
*  📅 Timeline: January 2024 – May 2026
*  📐 Dataset Size: 3,000 Rows | 10 Columns
*   💰 Total Revenue Analyzed: ~29M SAR
